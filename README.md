Summary of Work Process
In this assignment, I built an interactive single-page web portfolio leveraging jQuery to streamline DOM manipulation, event handling, visual effects, and custom CSS animations.

1. Setup & Selectors: Included jQuery via CDN and verified initialization using `$(document).ready()`. Implemented light/dark modes using `.addClass()` / `.removeClass()` and updated content dynamically using `.text()` and `.html()`.
2. Effects Used `.hide()`, `.show()`, `.toggle()`, `.fadeIn()`, `.fadeOut()`, `.fadeToggle()`, and `.slideToggle()` to build interactive visibility controls and accordion panels.
3DOM Manipulation: Enabled dynamic list additions (`.append()`, `.prepend()`) with input validation, modified element attributes via `.attr()`, and implemented real-time form mirroring with `.val()`.
   Animations: Built custom animated skill progress bars using jQuery's `.animate()` method to toggle fill widths between `0%` and target percentage levels.
